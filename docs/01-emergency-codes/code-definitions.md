# Emergency Code Definitions — Code 1 and Code 2

## Authority

เอกสารนี้บันทึกนิยามล่าสุดที่ได้รับการอนุมัติจาก **KB Owner — Sittipong** และให้ใช้เป็นนิยามหลักในการตีความ Code 1 และ Code 2

หากข้อความนิยามในเอกสาร Code 1 หรือ Code 2 ฉบับก่อนหน้าขัดกับนิยามในเอกสารนี้ ให้ยึดนิยามที่ได้รับอนุมัติในเอกสารนี้เป็นหลัก โดยรายละเอียด Workflow และขั้นตอนปฏิบัติเดิมยังคงใช้ได้ตราบเท่าที่ไม่ได้ขัดกับนิยามล่าสุดหรือถูกแก้ไขโดย KB Owner

## Code 1

**Code 1 = รับรู้/รับแจ้ง (Acknowledge)**

Code 1 ให้ตีความหลักว่าเป็นสถานะ **Acknowledge — รับรู้/รับแจ้งเหตุ**

## Code 2

**Code 2 = Real Fire**

Code 2 ให้ตีความหลักว่าเป็น **เหตุเพลิงไหม้จริง (Real Fire)**
