# Code Sierra — Active Shooter Emergency Procedure

## 1. Purpose
Code Sierra is the emergency procedure for an Active Shooter incident within One Bangkok. Its primary focus is Life Safety, area control, coordinated emergency response, and support to Police operations.

## 2. Definition & Trigger
- **Code Sierra = Active Shooter / เหตุกราดยิง**
- Trigger: an Active Shooter incident occurs within One Bangkok.
- Canonical spelling is **Code Sierra**. Do not use `Code Seirra`.
- Activation places relevant teams into the highest emergency response mode and initiates coordinated response, Lockdown, and traffic control.

## 3. SOC First Action
Operational flow:

**Receive Report → Review CCTV / Video Analytic → Inform DCC → Verify Situation → Create Mozart Case & Task → External Coordination → Prepare DCC Alignment / PA Code Sierra**

- Upon receiving a report from field security or a person at the scene, SOC reviews CCTV and Video Analytic as quickly as possible and informs DCC immediately.
- After confirmation, SOC creates a Mozart Case using Event Type **Active Shooter – ก่อเหตุกราดยิง** and creates Task Incident notifications for relevant teams.
- SOC coordinates with Lumpini Police Station and network hospitals / ambulance support.
- SOC prepares DCC Alignment Room support and PA Code Sierra readiness.

## 4. Declaration Authority
- **DCC = Declaration Authority.**
- DCC receives/evaluates incident information and instructs SOC to announce Code Sierra.
- Operational logic: **DCC Authorizes → SOC Announces Code Sierra**.
- SOC is not the independent declaration authority under the currently confirmed knowledge.

## 5. Command Structure
### Level 1 — CMT / Strategic Level
CMT (Crisis Management Team) handles organization-level strategic decisions, business and safety impacts, long-term closure decisions, public/media communication, and coordination with government authorities at management level. The documented operating location is the **Viewing Lounge**.

### Level 2 — DCC + ERT / Operational Control
DCC and ERT operate jointly at **DCC Alignment**. DCC controls and decides evacuation, area restriction, and internal communication. ERT participates in situation assessment and approval of major safety measures such as Lockdown and cross-building evacuation.

### Level 3 — EOT / Tactical & Field
EOT acts as the field Incident Commander for field-force coordination. Its confirmed roles include supporting evacuation, coordination of casualty assistance, and supporting / guiding Police with field information.

### Level 4 — SOC / Information & Coordination
SOC provides Situation Awareness and coordination through real-time CCTV / Video Analytic monitoring, Mozart incident records, and external-agency coordination.

## 6. Communication
- **Emergency 1** is the primary emergency radio communication channel for relevant internal teams during Code Sierra.
- The currently confirmed source does not provide a complete team checklist or a confirmed backup radio channel specifically for Code Sierra.

## 7. Life Safety — RUN / HIDE / FIGHT
### RUN — หนีเมื่อปลอดภัย
Use RUN when a safe escape route exists and escape does not create a risk of encountering the attacker.
- Leave the dangerous area quickly.
- Leave belongings behind.
- Use the nearest safe escape route / fire escape and do not return toward the incident.
- Warn or assist others only when it does not create additional risk.
- Do not stop to photograph, record video, or livestream.
- Once clear of danger, move to a designated safe area or Assembly Point.

### HIDE — ซ่อนเมื่อหนีไม่ได้
Use HIDE when there is no safe escape route, the route is blocked, or attempting to run creates a risk of encountering the attacker.
- Use solid cover or a room that can be closed and locked.
- Lock and barricade doors where possible.
- Turn off lights.
- Silence mobile phones completely, including vibration.
- Stay out of sight and remain quiet.

### FIGHT — ต่อสู้เป็นทางเลือกสุดท้าย
Use FIGHT only as a last resort when escape and hiding are not possible and there is an immediate threat to life.
- The objective is immediate personal survival, not pursuit or apprehension of the attacker.
- Do not leave a safe location to seek confrontation.
- Security / EOT operational boundaries in Section 10 remain unchanged.

## 8. Lockdown
Lockdown is implemented under the decision of **DCC + ERT** after Code Sierra activation.

Operational flow:

**DCC + ERT Decision → DCC instructs SOC → SOC distributes command / Mozart Task → BMO + FMC + TMT execute concurrently**

Confirmed execution roles:
- **BMO:** Access Control / door control.
- **FMC:** elevator and HVAC control.
- **TMT:** external traffic restriction and emergency-vehicle access.

The documented Lockdown scope includes Common Infrastructure (CI), Retail, Towers, Hotel, and Condominium areas of One Bangkok.

## 9. Evacuation
**Code Sierra ≠ Automatic Evacuation.**

Evacuation must not direct occupants toward the attacker. It must consider official instructions and whether a safe route is available. PA Code Sierra, Contact Centre information, and guidance by Security / EOT may form part of the evacuation process.

Individual life-safety logic:
- **Safe escape route → RUN**
- **Unsafe / blocked escape route → HIDE**
- **Immediate life threat when RUN and HIDE are not possible → FIGHT as a last resort**

## 10. Security / EOT Safety Boundary
- Security and EOT are **not tactical engagement or suspect-apprehension units**.
- Security verifies initial information from a safe distance, reports to SOC, restricts areas, and supports evacuation.
- Security and EOT must avoid approaching the Hot Zone.
- EOT supports evacuation, first aid, and casualty movement to a Safe Zone within the confirmed safety conditions.
- Control, neutralization, and arrest of the attacker are Police responsibilities.
- The individual **FIGHT** life-safety principle does not authorize Security / EOT to pursue, tactically engage, or apprehend the attacker.

## 11. Medical Response
- Code Sierra references **OB-SOP-EP-0007 — แผนบริหารจัดการผู้ป่วยฉุกเฉิน** for detailed medical response.
- SOC coordinates hospitals and external emergency medical / rescue support.
- EOT supports initial first aid and movement of casualties within its confirmed scope.
- The source document OB-SOP-EP-0007 is currently unavailable to this KB; detailed Medical / Triage procedures must not be invented.

## 12. Police Arrival & Transfer of Command
- TMT guides arriving Police toward One Power (CUP) using the safest and fastest available route described by the current source.
- SOC continuously supports DCC with CCTV / Video Analytic intelligence about attacker description, weapon information, and location/movement when available.
- **DCC + ERT** perform Transfer of Command to Police and provide relevant incident information, Floor Plan, and system information.
- After Transfer of Command: **Police = Incident Control; One Bangkok teams = Support Police Operations as requested.**

## 13. Code Sierra Termination
- Code Sierra is terminated only after official Police confirmation that the incident has ended.
- **DCC Incident Commander = Code Sierra Termination Authority.**
- **Terminate Code Sierra ≠ Re-entry.** Re-entry is a separate approval process.

## 14. Recovery
Confirmed recovery responsibilities include:
- **FMC:** assess and restore critical building systems, preserve relevant system information/evidence, coordinate repair and verification.
- **BMO:** coordinate area recovery after permission and prepare the applicable incident investigation report.
- **Safety:** review investigation findings and recommend corrective / preventive measures.
- **SOC:** assess CCTV / Video Analytic systems and preserve incident footage as evidence.
- **DCC:** manage internal incident/recovery communication and information control.
- **BMO & CRM:** provide recovery updates to tenants and relevant support information.
- **ERT and relevant parties:** conduct Post-Incident Review and capture lessons learned.

## 15. Mozart Case Closure
After Police control the incident and the DCC Incident Commander terminates Code Sierra:

**SOC → Incident Summary → Update Mozart → Close Case → DCC verifies complete case closure**

The current confirmed knowledge does not establish mandatory Mozart closure fields or mandatory evidence attachments.

## 16. AI Guardrails
1. Code Sierra means Active Shooter.
2. Use **Code Sierra** as the canonical term.
3. DCC is Declaration Authority; SOC performs the announcement following DCC authorization.
4. Do not interpret Code Sierra as Fire Code 1 / Code 2 / Code 3.
5. Code Sierra does not mean automatic evacuation.
6. Apply **RUN / HIDE / FIGHT** according to actual safety conditions; FIGHT is a last resort when RUN and HIDE are not possible and there is an immediate threat to life.
7. Security / EOT must not be instructed to pursue, tactically engage, or apprehend the Active Shooter; the individual FIGHT principle does not change this operational boundary.
8. Police are responsible for controlling / neutralizing / apprehending the attacker.
9. After Transfer of Command, One Bangkok teams support Police operations as requested.
10. AI must not independently declare Code Sierra termination or All Clear.
11. **Terminate Code Sierra ≠ Re-entry.**
12. Do not invent a PA Code Sierra script.
13. Do not invent Medical / Triage procedures from the unavailable OB-SOP-EP-0007.
14. Do not convert proposed Mozart fields/evidence into mandatory SOP requirements.
15. Do not invent named persons, Police tactical procedures, Unified Command Post locations, or other operational facts not supported by approved knowledge.
