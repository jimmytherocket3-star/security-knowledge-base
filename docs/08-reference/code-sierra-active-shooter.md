# Code Sierra — Active Shooter

## Definition
- Code Sierra = Active Shooter (เหตุกราดยิง)

## Safety Principle
**RUN – HIDE – FIGHT**

- RUN — หากสามารถหลบหนีออกจากพื้นที่อันตรายได้อย่างปลอดภัย ให้หลบหนี
- HIDE — หากไม่สามารถหลบหนีได้ ให้หาที่กำบัง/ซ่อนตัวและลดโอกาสถูกพบ
- FIGHT — ใช้เป็นทางเลือกสุดท้ายเมื่อเผชิญอันตรายโดยตรงและจำเป็นต้องป้องกันชีวิต

## Knowledge Base Rule
สำหรับ Code Sierra ให้ใช้หลัก **RUN – HIDE – FIGHT** และไม่ใช้ RUN – HIDE – TELL
