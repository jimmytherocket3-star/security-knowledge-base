# ONE Bangkok Assembly Points & Fire Truck Parking Points

Source: ONE Bangkok reference image — แผนผังจุดรวมพลและจุดจอดรถดับเพลิง โครงการ วัน แบงค็อก. Provided and approved by KB Owner.

## Assembly Points (จุดรวมพล)
จากสัญลักษณ์จุดรวมพลสีเขียวในแผนผัง มีจุดหลักดังนี้:
- บริเวณ The Storeys
- บริเวณ One Bangkok Park
- บริเวณด้านหน้า Parade ริมถนนพระราม 4

> หมายเหตุ: หมายเลข 1–5 บนแผนผังเป็นจุดจอดรถดับเพลิงสำหรับอาคาร ไม่ใช่หมายเลขจุดรวมพล

## Fire Truck Parking Points (จุดจอดรถดับเพลิง)
| หมายเลข | อาคาร | สถานที่ |
|---|---|---|
| 1 | วัน แบงค็อก ทาวเวอร์โฟร์, พาเหรด และเดอะ สตอรีส์ | จุดรับ-ส่ง อาคารเดอะ สตอรีส์ ทางเข้า 2 |
| 2 | วัน แบงค็อก ทาวเวอร์ทรี | ถนนพระรามที่ 4 ใกล้ทางเข้าที่ 3 |
| 3 | วัน พาวเวอร์ | ด้านหลังอาคาร วัน พาวเวอร์ |
| 4 | วัน แบงค็อก ฟอรั่ม | ด้านหลังอาคาร วัน แบงค็อก ฟอรั่ม |
| 5 | วัน แบงค็อก ทาวเวอร์ ไฟว์ | จุดรับ-ส่ง อาคาร โพสต์ ไนน์ทีน ทเวนตี้เอท |

## Operational Usage
ใช้เป็นข้อมูลอ้างอิงสำหรับ Code 3 / Evacuation และการประสานงานรถดับเพลิงภายใน ONE Bangkok โดยให้ยึดตำแหน่งตามแผนผังต้นฉบับที่ KB Owner ให้ไว้
