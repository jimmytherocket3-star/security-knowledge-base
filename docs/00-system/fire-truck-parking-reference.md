# One Bangkok Fire Truck Parking Reference

## Purpose

เอกสารนี้เป็น Reference สำหรับตอบคำถามเกี่ยวกับ **จุดจอดรถดับเพลิงสำหรับอาคาร** ตามแผนผัง One Bangkok ที่ KB Owner ให้ข้อมูลและอนุมัติเมื่อ 2026-09-08

## Approved Fire Truck Parking Mapping

| หมายเลข | อาคาร | จุดจอดรถดับเพลิง / สถานที่ |
|---|---|---|
| 1 | วัน แบงค็อก ทาวเวอร์โฟร์, พาเหรด และเดอะ สตอรี่ส์ | จุดรับ-ส่ง อาคารเดอะ สตอรี่ส์ ทางเข้า 2 |

## Quick Retrieval

- **Tower 4 / Parade / The Storeys** → จุดจอดรถดับเพลิงหมายเลข **1** → จุดรับ-ส่ง อาคาร The Storeys ทางเข้า 2
- **Tower 3** → จุดจอดรถดับเพลิงหมายเลข **2** → ถนนพระรามที่ 4 ใกล้ทางเข้าที่ 3
- **One Power** → จุดจอดรถดับเพลิงหมายเลข **3** → ด้านหลังอาคาร One Power
- **One Bangkok Forum** → จุดจอดรถดับเพลิงหมายเลข **4** → ด้านหลังอาคาร One Bangkok Forum
- **Tower 5** → จุดจอดรถดับเพลิงหมายเลข **5** → จุดรับ-ส่ง อาคาร Post 1928

## Guardrails

- หมายเลข **1–5** ในเอกสารนี้หมายถึง **จุดจอดรถดับเพลิง** ไม่ใช่ Assembly Point
- ห้ามนำหมายเลข 1–5 ไปตีความเป็นหมายเลขจุดรวมพล
- เอกสารนี้ไม่กำหนดเส้นทางการเข้าถึง จุดเข้าโครงการ หรือเส้นทางที่รถดับเพลิงต้องใช้ นอกเหนือจากสถานที่ที่ระบุในแหล่งข้อมูล
- เอกสารนี้ไม่เปลี่ยน Code 1 / Code 2 / Code 3 workflow หรือ Emergency Authority
- หากถามข้อมูลที่ไม่ได้ระบุใน Reference นี้ ให้ตรวจ KB source อื่นที่เกี่ยวข้องก่อน และหากยังไม่มีข้อมูลให้ถือเป็น Knowledge Gap
