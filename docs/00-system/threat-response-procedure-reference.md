## 1. Scope

---

## 2. Approved Knowledge

- ระเบียบปฏิบัติเพื่อรับมือภัยคุกคามแบ่งระดับการเฝ้าระวังออกเป็น **5 ระดับความรุนแรง** ตามความใกล้ตัวของเหตุการณ์
- มาตรการครอบคลุมการรักษาความปลอดภัยระดับเข้มงวด เช่น การคัดกรองบุคคลและยานพาหนะ
- ฝ่ายวิศวกรรมและบริการส่วนกลางต้องปรับแผนงานและเพิ่มความถี่ในการตรวจตราเครื่องจักรและพื้นที่สาธารณะตามระดับสถานการณ์
- ศูนย์รับเรื่องร้องเรียนต้องยกระดับการตรวจสอบสื่อสังคมออนไลน์และฝึกฝนทักษะการเจรจาเมื่อสถานการณ์ตึงเครียดขึ้น
- เมื่อเข้าสู่ระดับสูงสุด มีมาตรการจำกัดสิทธิ์การเข้าพื้นที่เฉพาะผู้ที่ได้รับอนุญาต และระงับการจัดกิจกรรมรวมถึงบริการรถรับส่งทั้งหมดเพื่อความปลอดภัยสูงสุด

---

## 3. AI Guardrails

- ข้อมูลต้นทางที่อนุมัติในครั้งนี้เป็นข้อมูลสรุประดับภาพรวม และไม่ได้ระบุชื่อ/สี/เกณฑ์ Trigger ของแต่ละระดับทั้ง 5 ระดับอย่างละเอียด
- ห้าม AI สร้างชื่อระดับ สี เกณฑ์ Trigger, Declaration Authority, ผู้มีอำนาจลด/ยกระดับ, SLA, workflow หรือมาตรการรายระดับเพิ่มเติมเอง
- ห้ามนำข้อมูลนี้ไปแทน Canonical Threat Level หรือ Emergency Code อื่นโดยอัตโนมัติ
- หากต้องตอบรายละเอียดที่แหล่งข้อมูลนี้ไม่รองรับ ให้ระบุเป็น **Knowledge Gap** และค้นแหล่ง Approved/Active อื่นใน Skills Hunter ตาม routing policy ก่อน
