## Rendering Rules
- Use the full approved signature, not only the company logo.
- Use the actual approved signature image inline.
- Do not replace contact details with placeholders such as `[ข้อมูลการติดต่อ]`.
- Do not replace the image with text such as `[โลโก้บริษัท]`.
- Do not treat a normal file attachment as a substitute for the inline signature image.
- Preserve the approved name, title, company, mobile number, email address, signature image, and ordering shown above.
- For Guard Tour email, use the approved To recipient above.
- CC information must not be inferred when not established.
