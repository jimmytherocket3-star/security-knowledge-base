# Guard Tour Email Writing Standard

## 1. Purpose

Define the approved format and drafting rules for Guard Tour emails prepared for the KB Owner.

## 2. Email Routing

**From:** Sittipong Homjai <sittipong.h@senses.co.th>  
**To:** _SENSES SOC Team <soc@senses.co.th>  
**CC:** Not established. Do not infer or add CC recipients without confirmed information.

When creating a Guard Tour Gmail Draft, populate `soc@senses.co.th` in the To field at draft creation time. Do not leave To blank.

## 3. Subject Format

Use:

**สรุปผลการปฏิบัติงาน Guard Tour อาคาร [ชื่ออาคาร] ประจำวันที่ [DD / MM / YYYY]**

Use the building name and date supported by the Guard Tour Report.

## 4. Opening

Use:

**เรียน ผู้เกี่ยวข้องทุกท่าน**

Then:

**ขอนำส่งสรุปผลการปฏิบัติงาน Guard Tour อาคาร [ชื่ออาคาร] ประจำวันที่ [DD / MM / YYYY] ดังนี้**

## 5. Guard Tour Result

For each applicable round, present the confirmed report information, including when available:

- Guard Tour / Route name
- รอบเวลา
- Start
- Finish
- Duration
- Status
- Planned / Completed / Skip, or the report's supported completion figures

If one building has multiple rounds, keep the rounds in the same building email and separate the information by round.

## 6. Skip / Abnormal Findings

Show Skip or abnormal information supported by the Guard Tour Report.

Where available, include:
- Number of Skip points
- QR / point name
- Reason for Skip
- Relevant abnormal finding

If the report does not establish the reason for Skip, state that the report does not identify the reason. **Do not invent a reason.**

For a normal round/building with no abnormal item requiring explanation, keep the presentation concise and show the result figures rather than adding unnecessary narrative.

## 7. Supporting Report

State that detailed inspection results, Skip points, and photographs can be reviewed in the attached Guard Tour Report.

Attach the applicable Guard Tour Report for the round(s) covered by the email.

## 8. Closing

Use:

**จึงเรียนมาเพื่อทราบ**

Then apply the approved Full Email Signature Standard in:

`docs/00-system/email-signature-standard.md`

SOC Operator - Security Operation Centre (SOC)  
Senses Property Management Company Limited

Mobile : 085-112-8002

The approved Senses signature image belongs after the contact information according to the Full Email Signature Standard.

## 9. Current Gmail Tool Limitation

The current connected Gmail drafting tool does not support inserting the approved company signature image as an inline image in the generated Draft.

Therefore:
- Do not use `[โลโก้บริษัท]` as a substitute.
- Do not claim that the inline logo has been inserted when it has not.
- The KB Owner currently handles the inline company signature image separately.
- This limitation does not change the approved signature standard.

## 10. Draft Creation Rules

When the KB Owner requests creation of a Guard Tour Draft:

1. Use the Guard Tour Report as the factual source for operational results.
2. Set To = `soc@senses.co.th` at initial Draft creation.
3. Do not infer CC.
4. Use the approved subject and body structure.
5. Include confirmed Skip / abnormal information; do not invent missing causes.
6. Include the approved full contact block.
7. Attach the applicable Guard Tour Report.
8. Do not send the email unless the KB Owner explicitly instructs sending.
9. Leave the Draft for KB Owner review and manual handling of the inline company signature image when required.
