# One Bangkok Location & Building Directory

## Purpose

This document is the approved Knowledge Base reference framework for official place and building naming within the project. It is intended to support consistent location identification in incident communication, check-in references, reports, and emergency procedures.

## Confirmed Source Scope

The approved source confirms that the reference set covers multiple location types within the project, including:

- Office buildings / towers
- Residential areas
- International hotels
- Common areas
- Event / activity areas
- Museum-related locations
- Thai pronunciation guidance and specific naming references for English place names

## Intended KB Usage

Use this directory as the canonical location-naming reference layer when sufficient approved location details are available. Emergency procedures, incident reports, SOC case records, and training material may reference this directory for standardized place naming.

## Current Knowledge Limitation

The supplied Markdown source describes the purpose and categories of the location reference, but does not contain the underlying complete list of individual building/place names or their Thai pronunciations. Therefore, individual names must NOT be invented, reconstructed, or treated as confirmed from this source alone.

## AI Guardrails

1. Do not invent building names, place names, check-in points, or Thai pronunciations that are absent from approved source data.
2. Do not silently replace a source-specific location name with a guessed standardized name.
3. Distinguish a building, residential area, hotel, common area, event area, and other location types when the approved source identifies the category.
4. This directory standardizes location naming only; it does not change emergency SOP workflow, command authority, or response responsibilities.
5. When an emergency procedure refers to a location, use the approved location name where available and preserve the incident-specific floor/zone/area details.
6. Additional individual location names or pronunciation mappings require KB Owner review and approval before being added.
