## 3. Test Criteria / Key Values

### Lift
- Load Test ต้องใช้น้ำหนัก **ไม่น้อยกว่า 100%** ของน้ำหนักใช้งานสูงสุดที่ผู้ผลิตกำหนด.

### Fire Extinguisher — Gauge Type
- Source states Normal / Pass: เข็มอยู่ในแถบสีเขียว; source summary specifies **195 psi** as normal pressure.
- Source states Low / Recharge: เข็มต่ำกว่านอกแถบสีเขียว; summary expresses this as **<195 psi**.
- Source states Overcharge: เข็มสูงกว่านอกแถบสีเขียว; summary states **>1,000 psi** may present explosion danger and requires urgent correction.

### CO2 Fire Extinguisher — No Gauge
- ใช้วิธีชั่งน้ำหนัก.
- หากปริมาณ/น้ำหนักก๊าซภายใน **ต่ำกว่า 80%** ถือว่าไม่ผ่านและต้องส่งบรรจุใหม่ทันที.

### Light Meter
- สอบเทียบ/ปรับเทียบความถูกต้องกับหน่วยปรับเทียบมาตรฐาน.

### Crane Capacity Bands
- 1–3 ตัน
- >3–50 ตัน
- >50 ตัน

### Electrical Inspection Reporting
- แจ้งผลต่อพนักงานตรวจความปลอดภัยภายใน **15 วัน** นับแต่วันตรวจ.

## 4. Responsibility / Document Authority

### Lift Tester / Certifier
Source summary states: วิศวกรตามกฎหมายกระทรวง หรือบุคคลที่ขึ้นทะเบียนตามมาตรา 9 / นิติบุคคลตามมาตรา 11 แห่ง พ.ร.บ. ความปลอดภัย อาชีวอนามัย และสภาพแวดล้อมในการทำงาน พ.ศ. 2554.

### Fire Extinguisher >5 Years
ส่งตรวจสอบกับบริษัทที่มีความเชี่ยวชาญและมีมาตรฐานรองรับ.

### SOP Document Approval
- **Prepared by:** Safety Supervisor (JLL)
- **Verified by:** Safety Manager (JLL) และ Deputy Director, Property and Asset Management (JLL)
- **Approved by:** Vice President, Facility Management - Integrated Operations Control (FPMST)
